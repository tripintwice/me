# Как самому задеплоить на GitHub Pages

## Автоматический деплой (уже настроен):

Каждый раз когда ты делаешь `git push origin main`, GitHub автоматически:
1. Запускает GitHub Actions
2. Устанавливает зависимости (`npm ci`)
3. Собирает проект (`npm run build`)
4. Деплоит на GitHub Pages

## Проверить статус деплоя:

1. Зайди на https://github.com/tripintwice/bio
2. Нажми на вкладку **Actions** (вверху)
3. Увидишь список всех деплоев
4. Зеленая галочка ✅ = успешно
5. Красный крестик ❌ = ошибка (можно кликнуть и посмотреть логи)

## Ручной деплой (если нужно):

Если хочешь запустить деплой вручную без изменений:

```bash
# Сделай пустой коммит
git commit --allow-empty -m "trigger deploy"

# Запушь
git push origin main
```

## Где смотреть сайт:

Твой сайт: https://tripintwice.github.io/bio/

## Что делать если деплой не работает:

1. Зайди в **Settings** репозитория
2. Слева найди **Pages**
3. Проверь что:
   - Source: **GitHub Actions**
   - Branch: не важно (используем Actions)
4. Репозиторий должен быть **Public** (приватные требуют Pro)

## Локальная проверка перед деплоем:

```bash
# Собери проект локально
npm run build

# Превью собранной версии
npm run preview
```

Откроется на http://localhost:4173 - так будет выглядеть на продакшене.
